# PromptLens · 图片反推提示词（Chrome 扩展）

网页上看到一张图，右键它，就在当前页面弹出这张图可用的 AI 生图提示词。

不跳转页面、不上传素材库、不用复制图片地址——**右键 → 出结果 → 复制**，三步结束。

默认输出 7 段，每段可单独复制：

| 分块 | 内容 | 用途 |
|---|---|---|
| 画面类型 | 「主要类型｜具体类型」，如 `海报｜黑底扁平插画信息图` | 先定图片属于哪一类，后续分析才不跑偏 |
| 中文描述 | 100–180 字客观描述，按图片类型自动切换描述顺序 | 看懂这张图好在哪 |
| 构图控制 | 3–6 条布局约束，如「主体居中偏左，约占画面三分之一」 | 直接用于生图 / 图生图的空间控制 |
| 文字处理 | 逐条列出文字内容、位置、字形，并给出「后期叠字 / 保留空白区 / 英文占位 / 保留原文」建议 | 解决 AI 生成文字必崩的问题 |
| 英文 Prompt | 逗号分隔标签短语，主体与核心构图在前半部分 | 直接粘给 Midjourney / Stable Diffusion / Flux / 即梦 / 豆包 |
| 反向提示词 | 英文 Negative Prompt，按图片类型选择，不堆砌 | 配套使用，避开常见瑕疵 |
| 标签 | 8–15 个中文关键词 | 素材归档、检索、训练 LoRA 打标 |

模板内置**三档**，设置页可一键切换（见 [设置项说明](#设置项说明)）。

与简单罗列物体的反推不同，这套模板强制模型**先判断图片类型**（摄影 / 海报 / 产品 / UI / 插画…），再按对应维度分析，并明确禁止虚构元素、禁止堆砌 `masterpiece` 这类无效词、禁止在 Prompt 里写品牌名与技术参数。

## 安装

**方式一：加载文件夹（推荐，也方便后续更新）**

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）
2. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车（Edge 用 `edge://extensions/`）
3. 打开右上角「**开发者模式**」
4. 点「**加载已解压的扩展程序**」，选择 `prompt-lens` 文件夹（**内含 manifest.json 的那一层**，不要选外层父目录）
5. 工具栏出现紫色眼睛图标即成功，建议点图钉固定

**方式二：直接装打包好的 zip**

仓库 Releases 里提供 `prompt-lens-v*.zip`，下载解压后按上面第 2 步开始，选解压出的 `prompt-lens` 文件夹。

> 更新扩展后，记得回到 `chrome://extensions/` 点一下扩展卡片上的**刷新 ↻**，否则跑的还是旧代码。

## 配置 API（只做一次）

扩展本身不"看图"，它需要调用一个**支持图片输入的视觉大模型**来完成反推。所以你需要一个 API Key。

**推荐智谱 `glm-4v-flash`：免费、不用绑卡、响应快**，日常够用。

1. 去 [open.bigmodel.cn](https://open.bigmodel.cn/usercenter/apikeys) 注册并复制 Key
2. 点浏览器工具栏的紫色眼睛图标 →「**打开设置**」
3. 服务商选「智谱 GLM」，模型名保持 `glm-4v-flash`
4. 粘贴 Key → 点「**保存设置**」
5. 点「**测试连接**」，出现一段示例文字就通了

之后就不用再管了。

> **能不能看图，只看具体模型名，不看厂商**——同一家往往文本版和视觉版并存。
> 例如 DeepSeek 目前只有 `deepseek-v4-flash-vision-exp` 能看图，其余（V4-Flash / V4-Pro / V3 / R1）都是纯文本，填了会报错。
> 模型名输入框点一下会弹出该服务商的**可用视觉模型清单**，从里面选最省心。

## 日常使用

| 操作 | 方法 |
|---|---|
| 触发 | 右键网页图片 →「反推这张图的提示词」 |
| 触发（另一种） | 鼠标停在图片上 → 点左上角浮现的「反推提示词」按钮 |

## 设置项说明

设置页（点扩展图标 → 打开设置）只有三块：

**模型接口**

- 服务商预设：选一家，会自动填好 Base URL 和推荐模型
- Base URL / API Key / 模型名：也可以全部手填，接任何 OpenAI 兼容接口
- 模型名输入框点一下会弹出该服务商的可用视觉模型清单

**输出格式**

- **模板预设**：三档，切换后点保存生效
  - **精简（4 段）**：中文描述、英文 Prompt、反向提示词、标签。输出短、速度快
  - **标准（7 段，默认）**：再加画面类型、构图控制、文字处理。绝大多数场景用它
  - **完整（9 段）**：再加视觉 DNA 与复现建议（画幅 / 生成模式 / 参考图依赖 / 结构控制 / 复刻难点）。信息最全，但对模型指令跟随能力要求高，弱模型可能漏段，建议把 tokens 调到 3000 以上
- **目标生图模型**：影响 Prompt 措辞。选 Flux 时会自动跳过反向提示词（Flux 不支持 Negative Prompt）
- **反推模板**：模型严格按这个模板输出，可自由改写。想只要英文 Prompt、或改成训练 LoRA 打标格式，直接改这段文字即可
- **最大输出 tokens**：默认 2500（标准版约需 1200–1800）。只有结果出现「输出半截」时才需要调大

**交互方式**

- 悬停按钮：不想看到浮动按钮可关掉，右键菜单不受影响
- 自动复制：分析完自动把全文复制进剪贴板

## 隐私与安全

这一点值得先说清楚：

- **只在你点下右键时才会发请求**，平时扩展不做任何网络动作
- 图片只发送给你**自己配置的那家 API 服务商**，扩展作者和任何第三方都收不到
- **API Key 只存在你本机浏览器的 `chrome.storage.sync` 里**，不会上传到任何服务器
- 图片优先以 URL 形式发送；遇到防盗链才会下载转 base64 再发一次（超过 3MB 会拦截，避免卡住）
- 没有埋点、没有统计、没有账号体系
- 全部源码就在本仓库，可以自己查

## 常见问题

**反推出来的就是原作者的 Prompt 吗？**

不是。这是基于画面内容**重新描述**出来的近似提示词，不是原始 Prompt。如果图片本身带 Stable Diffusion / NovelAI 的 PNG 元数据，直接读元数据会准得多——这个功能还没做，欢迎提 Issue。

**一定要 API Key 吗？有免费的吗？**

要，因为看图必须调模型。但**智谱 `glm-4v-flash` 永久免费**，不用绑卡，日常量完全够。

**为什么有些图片失败？**

最常见是防盗链（网站禁止外部读取图片）。扩展会自动下载转 base64 重试一次；超过 3MB 的大图会被拦下。

**支持截图选区反推吗？**

暂不支持，目前只能对网页上的 `<img>` 图片右键或悬停。

**能用在 Edge / Brave 上吗？**

能。任何 Chromium 内核浏览器都可以，Edge 用 `edge://extensions/` 加载。

**结果窗口位置能改吗？**

能，拖住顶部紫色标题栏拖动即可，位置会记住。

## 报错对照表

扩展已把常见错误翻译成中文，照着处理即可：

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 401 / Key 无效 | API Key 填错或过期 | 重新去服务商后台复制 Key |
| 404 找不到模型 | 模型名拼错，或该模型不支持图片输入 | 检查模型名；确认是视觉模型不是纯文本版 |
| 400 请求被拒绝 | 最常见是这个模型**不支持图片输入** | 换一个视觉模型（见上表） |
| 429 限流 / 余额不足 | 请求太频繁或账户没钱 | 等一会，或去充值 / 换免费模型 |
| 请求超时 | 图太大或网络慢 | 重试；换更快的模型 |
| 图片超过 3MB | 防盗链回退下载时超限 | 换小一点的图 |

## 文件结构

```
prompt-lens/
├── manifest.json    # MV3 配置（权限、右键菜单、后台脚本）
├── background.js    # 右键菜单 + 调用视觉 API + 模型清单
├── content.js       # 悬停按钮 + 结果卡片（Shadow DOM 隔离样式）
├── options.html     # 设置页
├── options.js       # 设置页逻辑
├── popup.html       # 扩展图标弹窗（状态 + 设置入口）
├── popup.js
├── icons/           # 16 / 32 / 48 / 128 图标
├── LICENSE          # MIT
└── README.md
```

无构建步骤、无第三方依赖，纯原生 JS。改完代码在扩展页点刷新即可生效。

## 开发者

**改模型清单**：全部集中在 `background.js` 顶部的 `PROVIDERS` 数组，每家服务商包含 `baseUrl` / `keyUrl` / `defaultModel` / `models[]`（含 `rank` 1–4 与 `tag`）／ `note`。改这里即可，设置页的模型和说明会自动同步。

**已下架模型的自动迁移**：`background.js` 里的 `DEAD_MODELS` 映射表，用户已保存的失效模型名会在扩展启动时自动换成替代款并弹通知。

**需要的权限**：`contextMenus`（右键菜单）、`activeTab` / `scripting`（注入页面脚本）、`storage`（存配置）、`downloads` 相关（图片转 base64）、`host_permissions`（访问你配置的 API 地址）。
